06 / Правила применения

Делаем.

Крупные цифры Unbounded — главный герой экрана. Один градиент на экран. Много воздуха, стекло-панели, свечение только у живых значений (пульс, live-метрики).

Не делаем.

Не смешиваем три градиента в одном виджете. Не ставим текст на градиент без плашки. Не используем тонкие шрифты для цифр — цифры всегда 700+.
